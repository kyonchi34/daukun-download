HOW TO INSTALL

はじめるまでの、3ステップ。

Windows
  1. 01

    ダウンロード

    Windows版のインストーラーをPCに保存します。

  2. 02

    インストール

    EXEファイルを開き、画面の案内に沿ってインストールします。

  3. 03

    ログイン

    DAUKUN IDとパスワードでログインします。初回は管理者から受け取ったコードで登録してください。

  1. 01

    APKをダウンロード

    Android端末にAPKを保存します。

  2. 02

    インストール

    ダウンロードしたAPKを開きます。必要に応じてこの提供元からのインストールを許可してください。

  3. 03

    ログイン

    DAUKUN IDとパスワードでログインします。更新時は既存アプリを残して「更新」を選んでください。

    App Storeを開く

  2. 02

BEFORE YOU START

はじめる前に

DAUKUN IDがわからないときは？＋

ログイン済みのアプリのMY PAGEを確認するか、IDを発行した管理者にお問い合わせください。

Android版・iOS版はいつ使える？＋

Android版はベータ配布中です。iOS版は日本のApp Storeで正式配信中です。上の各タブから入手できます。

アプリに入るための登録は必要？＋

発行済みのDAUKUN IDとパスワードが必要です。初回登録には管理者から受け取ったコードを使用してください。
