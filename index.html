HOW TO INSTALL

はじめるまでの、3ステップ。

Windows
  1. 01

    ダウンロード

    「Windows版をダウンロード」から、インストーラーをPCに保存します。

  2. 02

    インストール

    保存したEXEファイルを開き、画面の案内に沿ってインストールします。

  3. 03

    IDを入力して参加

    DAUKUNを起動し、発行済みのDAUKUN IDを入力して参加します。

  1. 01

    APKをダウンロード

    Android端末で「Android版をダウンロード」を押し、APKの保存が完了するまで待ちます。

  2. 02

    ファイルを開いてインストール

    Filesなどの「ダウンロード」からAPKを開きます。インストールの許可を求められた場合は、開いたアプリの「この提供元を許可」をオンにして戻り、インストールします。

  3. 03

    IDを入力して参加

    DAUKUNを起動し、発行済みのDAUKUN IDを入力します。すでに利用中の方は、既存アプリを残したまま「更新」を選んでください。

BEFORE YOU START

はじめる前に

DAUKUN IDがわからないときは？＋

ログイン済みのPC版がある場合は、MY PAGEのID表示を確認してください。確認できない場合は、IDを発行した管理者にお問い合わせください。

Android版・iOS版はいつ使える？＋

Android版はベータ版を配布中です。上の「Android」タブからAPKをダウンロードできます。iOS版は対応準備中で、配布開始日は未定です。

アプリに入るための登録は必要？＋

利用には発行済みのDAUKUN IDが必要です。アプリのログイン画面でIDを入力してください。スパファンの初回登録時は、表示名も設定できます。
